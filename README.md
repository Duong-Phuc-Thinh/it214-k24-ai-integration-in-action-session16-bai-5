# Hệ Thống Flash Sale Chống Sập (Resilient System)\n\n## Giới thiệu\nBài tập thiết kế hệ thống Flash Sale chịu tải cao (5.000+ RPS), giải quyết các bài toán Cache Stampede, Cold Start và cơ chế Fallback khi Redis gặp sự cố.\n\n## Các chức năng chính\n1. **Cache Warm-up**: Nạp sẵn dữ liệu sản phẩm vào Redis trước sự kiện để chống Cold Start.\n2. **Locking & Single Flight (Cache Stampede Prevention)**: Đồng bộ hóa các request đồng thời khi cache miss để chỉ duy nhất một thread truy vấn Database.\n3. **Rate Limiter & Fallback**: Giới hạn số lượng request trực tiếp xuống Database khi Redis sập (Degraded Mode).\n\n## Hướng dẫn chạy chương trình\n1. Cài đặt các thư viện cần thiết:\n   ```bash\n   pip install redis\n   ```\n2. Khởi chạy file chính:\n   ```bash\n   python app.py\n   ```
